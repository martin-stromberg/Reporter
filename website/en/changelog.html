Changelog

The change history of Reporter is maintained in several places in the repository and on GitHub:

GitHub releases

The primary source for release information is the releases page of the repository. There you will find every published version including release candidates (pre-releases), the corresponding release notes and the build artifacts for each platform.

changes.log

For a detailed look at individual changes, the repository keeps changes.log — German-language entries per date and issue, covering everything from bug fixes to new features.

Release notes

The English release notes live in docs/RELEASE_NOTES.md in the repository and serve as the text source for the GitHub releases produced by the release pipeline.
