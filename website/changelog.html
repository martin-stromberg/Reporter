Changelog

Die Änderungshistorie von Reporter wird an mehreren Stellen im Repository und auf GitHub gepflegt:

GitHub-Releases

Die primäre Quelle für Versionshinweise ist die Releases-Seite des Repositories. Dort findest du jede veröffentlichte Version inklusive Release-Kandidaten (Pre-Releases), den zugehörigen Release Notes und den Build-Artefakten der jeweiligen Plattformen.

changes.log

Für den detaillierten Blick auf einzelne Änderungen führt das Repository die Datei changes.log — deutschsprachige Einträge pro Datum und Issue, von Bugfixes bis zu neuen Features.

Release Notes

Die englischsprachigen Release Notes liegen als docs/RELEASE_NOTES.md im Repository und dienen der Release-Pipeline als Textvorlage für die GitHub-Releases.
