# Website

Die öffentliche Projekt-Website der Reporter-App ist eine zweisprachige (deutsch/englisch) statische Site unter `website/` im Repository. Sie bündelt Landing-Page, Datenschutzerklärung, Changelog-Verweise und ein Press Kit und wird über einen GitHub-Actions-Workflow auf GitHub Pages unter `https://martin-stromberg.github.io/Reporter/` veröffentlicht. Zielgruppe dieser Dokumentation sind Maintainer und Betreiber des Repositories.
