# Kategorien verwalten

Über den Tab **Kategorien** kannst du Kategorien für Feeds anlegen, umbenennen und löschen.

## Kategorie anlegen

1. Tippe in das Feld **Name**.
2. Gib einen Namen ein.
3. Tippe auf **Speichern**.

Die Liste zeigt die neue Kategorie und (später) die Anzahl der zugeordneten Feeds an.

## Kategorie umbenennen

1. Tippe neben der gewünschten Kategorie auf **Bearbeiten**.
2. Ändere den Namen im Eingabefeld.
3. Tippe auf **Speichern**.

Ein leerer oder bereits vorhandener Name wird abgelehnt.

## Kategorie löschen

1. Tippe neben der Kategorie auf **Löschen**.
2. Die Kategorie wird entfernt; zugeordnete Feeds verlieren automatisch ihre Kategorie-Zuordnung.
