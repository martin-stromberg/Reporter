# Security Policy

## Unterstützte Versionen

Sicherheitsrelevante Fixes werden auf dem aktuellen Stand von `main` bereitgestellt (jeweils neuestes Release). Ältere Versionen und Vorabversionen (`*-rc.*`) werden nicht gesondert gepflegt.

## Sicherheitslücken melden

Bitte melde Sicherheitslücken **nicht** über ein öffentliches Issue. Nutze stattdessen eine der folgenden Möglichkeiten:

- **GitHub Security Advisories:** [Privat melden](https://github.com/martin-stromberg/Reporter/security/advisories/new) — der Bericht bleibt bis zur Behebung vertraulich.
- **E-Mail:** <mstromberg84+reporter@gmail.com>

Bitte beschreibe die Lücke so konkret wie möglich (betroffene Version, Reproduktionsschritte, potenzielle Auswirkung). Ich bestätige den Eingang zeitnah und melde mich mit einer Einschätzung bzw. einem Fix-Zeitplan zurück.
